# 나의 작은 기록장 📓

코딩을 몰라도 운영할 수 있는 개인 블로그입니다.
글을 쓰면 인터넷에 자동으로 공개됩니다.

---

## 🚀 처음 한 번만 하면 되는 설정 (인터넷에 공개하기)

이 블로그를 인터넷에 띄우려면 GitHub Pages 기능을 켜야 해요.
**딱 한 번만** 하면 됩니다.

1. 인터넷 브라우저에서 내 GitHub 저장소 페이지로 갑니다.
   (주소: `https://github.com/sise0/sise.ver.1`)
2. 위쪽 메뉴에서 **Settings**(설정) 를 누릅니다.
3. 왼쪽 메뉴에서 **Pages** 를 누릅니다.
4. **Branch**(브랜치) 항목에서 `main` 을 고르고, 폴더는 `/ (root)` 로 둔 뒤
   **Save**(저장) 를 누릅니다.
5. 1~2분 기다리면 같은 화면에 내 블로그 주소가 나타납니다.
   보통 이런 모양이에요:

   ```
   https://sise0.github.io/sise.ver.1/
   ```

   이 주소를 누구에게나 공유할 수 있어요! 🎉

> 💡 참고: 위 4단계에서 고른 브랜치가 `main`이 아니라면,
> `_config.yml` 파일은 그대로 두어도 됩니다. 주소만 달라질 수 있어요.

## 🎨 블로그 이름·소개 바꾸기

- 블로그 제목, 소개글, 이름 → **`_config.yml`** 파일에서 따옴표 안 글자만 수정
- 색깔, 글씨 크기 → **`assets/style.css`** 파일 맨 위 설명을 참고

---

## 📁 폴더 설명 (참고용, 안 봐도 돼요)

| 폴더/파일 | 하는 일 |
|---|---|
| `_posts/` | 내가 쓴 글들이 들어가는 곳 |
| `_config.yml` | 블로그 제목·소개 등 기본 설정 |
| `assets/style.css` | 블로그 디자인(색·글씨) |
| `index.html` | 글 목록을 보여주는 첫 화면 |
| `_layouts/` | 페이지의 공통 틀 (건드릴 필요 없음) |
